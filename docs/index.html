Architecture & Engineering

Built for Sovereignty, Speed, and Simplicity

No external database clusters. No vendor lock-in. No SaaS invoices. Engineered as a single binary with zero operational friction.

Single-Binary Architecture

KestrelScope bundles the Kestrel web server, static UI assets, OTLP ingestion controllers, background alert evaluation workers, and an embedded SQLite database inside a single compiled .NET 9 binary. No ClickHouse, PostgreSQL, or Redis containers to maintain.

100% Air-Gapped & Sovereign

Telemetry never leaves your infrastructure. Strict zero-CDN frontend design ensures complete operational compliance with HIPAA, SOC2, defense, and high-security air-gapped data centers.

Standard OpenTelemetry (OTLP)

Zero proprietary agents. Send standard OTLP/HTTP payloads directly from any language SDK (.NET, Go, Python, Java, Node.js) or route through OpenTelemetry Collector sidecars.

High-Throughput SQLite WAL & Dapper

Configured with Write-Ahead Logging (PRAGMA journal_mode=WAL;) and optimized Dapper queries. Ingest thousands of spans, metrics, and structured logs per second concurrently with zero lock contention and microsecond read latencies.

Automated Alert Worker

Embedded background worker evaluates threshold rules every 60s and dispatches instant webhooks to Slack, Discord, Microsoft Teams, or custom incident management systems.

Built-In Database Lifecycle & Hot Backups

Native SQLite Online Backup API generates crash-consistent, non-blocking snapshots with streaming Gzip compression (.db.gz) and SHA256 checksums while writes remain active. Features chunked batch pruning (5,000 rows/chunk), dry-run simulations, WAL checkpoint flushes, vacuum compaction, and automated safety rollback snapshots on disaster recovery restore.

Role-Based Access & SOC2 Audit Trail

Built-in role-based security strictly separating Administrators from Standard viewers. Every retention policy adjustment, pruning run, backup creation, and restore operation is permanently recorded in an immutable audit trail table for compliance.

Instant Integration

Start Ingesting Telemetry in Under 2 Minutes

Choose your favorite runtime or tool and connect to KestrelScope's standard OTLP receivers. 

services:
  kestrelscope:
    image: mindslost/kestrelscope:latest
    container_name: kestrelscope
    ports:
      - "5000:5000"
    environment:
      - ASPNETCORE_ENVIRONMENT=Production
    volumes:
      - kestrel_data:/app/data
    restart: unless-stopped

volumes:
  kestrel_data:
// Program.cs (.NET 8 / 9)
builder.Services.AddOpenTelemetry()
    .WithTracing(tracing => tracing
        .AddAspNetCoreInstrumentation()
        .AddHttpClientInstrumentation()
        .AddOtlpExporter(opt => opt.Endpoint = new Uri("http://localhost:5000/v1/traces")))
    .WithMetrics(metrics => metrics
        .AddAspNetCoreInstrumentation()
        .AddOtlpExporter(opt => opt.Endpoint = new Uri("http://localhost:5000/v1/metrics")));
// tracing.js (Node.js OpenTelemetry SDK)
const { NodeSDK } = require('@opentelemetry/sdk-node');
const { OTLPTraceExporter } = require('@opentelemetry/exporter-trace-otlp-http');

const sdk = new NodeSDK({
  traceExporter: new OTLPTraceExporter({
    url: 'http://localhost:5000/v1/traces',
  }),
});
sdk.start();
# Standard OpenTelemetry environment variables
export OTEL_SERVICE_NAME="payment-api"
export OTEL_EXPORTER_OTLP_ENDPOINT="http://localhost:5000"
export OTEL_EXPORTER_OTLP_PROTOCOL="http/json"

# Run your FastAPI / Flask service with automatic instrumentation:
opentelemetry-instrument uvicorn main:app --port 8000
